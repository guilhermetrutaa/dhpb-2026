# Checklist de qualidade da spec

Marque só após revisão humana. Item marcado **não** significa implementação pronta.

- [x] Problema e aceite estão testáveis
- [x] As-is foi conferido no código (docs podem estar desatualizados)
- [x] Escopo negativo lista módulos sensíveis fora desta feature
- [x] Leituras/writes Firestore estão explícitas (Spark)
- [x] Firebase (principal vs suporte) está definido
- [x] Required reading tem no máximo 6 arquivos
- [x] Constitution aplicável está citada
- [x] Se toca pontuação, `membro-index`, `aprovadoAte` ou isolamento do chat: humano aprovou esta spec
