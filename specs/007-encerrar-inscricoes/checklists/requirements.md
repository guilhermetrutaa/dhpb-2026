# Checklist de qualidade da spec

Marque so apos revisao humana. Item marcado **nao** significa implementacao pronta.

- [x] Problema e aceite estao testaveis
- [x] As-is foi conferido no codigo (docs podem estar desatualizados)
- [x] Escopo negativo lista modulos sensiveis fora desta feature
- [x] Leituras/writes Firestore estao explicitas (Spark)
- [x] Firebase (principal vs suporte) esta definido
- [x] Required reading tem no maximo 6 arquivos
- [x] Constitution aplicavel esta citada
- [x] Se toca pontuacao, `membro-index`, `aprovadoAte` ou isolamento do chat: humano aprovou esta spec
