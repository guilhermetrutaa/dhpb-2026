# Checklist de qualidade da spec

Marque só após revisão humana. Item marcado **não** significa implementação pronta.

- [ ] Problema e aceite estão testáveis
- [ ] As-is foi conferido no código (docs podem estar desatualizados)
- [ ] Escopo negativo lista módulos sensíveis fora desta feature
- [ ] Leituras/writes Firestore estão explícitas (Spark)
- [ ] Firebase (principal vs suporte) está definido
- [ ] Required reading tem no máximo 6 arquivos
- [ ] Constitution aplicável está citada
- [ ] Se toca pontuação, `membro-index`, `aprovadoAte` ou isolamento do chat: humano aprovou esta spec
